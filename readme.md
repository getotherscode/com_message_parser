# Brief 
this is a com message parser untils, you can use config.toml to describe your message struct, and the program will parse the message automatically
## support platform
Windows
## language
python
## library
1. pip: python pack manage
2. pyserial: get windows com obj
3. rich: format data in terminal
4. tomlib: parse TOML file
5. crcmod: modbus crc calculation
